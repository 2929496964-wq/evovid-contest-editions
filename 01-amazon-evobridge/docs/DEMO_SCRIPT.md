## 0:00–0:15 — Honest introduction

Show the empty studio and its disclosure.
“EvoBridge is an Alexa+ experience simulation for small creators. AI tools helped build it; runtime interactions use clear deterministic rules. It does not connect to the Alexa+ service.”

## 0:15–0:45 — Create a brief in conversation

Type `Create a project`. Answer `The corner café`, `our neighborhood`, `12`, `warm`. Let each prompt and state change remain visible.
“The assistant collects the missing pieces of a brief, then turns them into an editable three-scene template. Everything stays on this computer.”

Type `Shorten scene 2`; show the time shrinking from 12 to 11 seconds. Type `Text 2: A little pause. A familiar face.` Select scene 2 and show the changed caption. Type `Undo`; then apply the caption again in the inspector.
“Commands change real project data. Direct controls and undo keep the creator in charge.”

## 1:05–1:25 — Material and format

Optionally add an image you own and apply it to scene 2; skip this if no licensed demo asset is prepared. Change the scene animation to Rise. Show portrait and return to landscape.
“These are local motion graphics with optional images, not neural text-to-video.”

## 1:25–1:50 — Confirm, cancel, then render

Click Export. Point out the exact revision and duration. Click Not yet and show no render starts. Open Export again and confirm. Leave actual progress visible; do not overlay a fabricated progress animation.
“A render begins only after confirmation. Repeated clicks reuse the same job, and a running render can be cancelled.”

## 1:50–2:15 — Play and inspect the actual result

Wait for genuine completion. Play the video for 8–11 seconds. Download MP4 and show the evidence JSON link. If real rendering needs longer, shorten prior narration rather than hiding the result.
“This MP4 was created from this revision. Its evidence manifest records the input, output size and SHA-256.”

## 2:15–2:35 — Persistence and close

Reload the page, show saved storyboard and history, then show project JSON backup/restore.
“Close and reopen without losing your storyboard. EvoBridge makes the path from a small idea to a real, shareable video simple, inspectable and private.”
