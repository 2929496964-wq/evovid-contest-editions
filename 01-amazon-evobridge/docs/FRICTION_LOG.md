# Actual friction log — 2026-10-11

1. **Upstream scope mismatch.** The public EvoVid snapshot is an iOS/Pocket prototype plus optional desktop workbench. Reusing the full stack would bring unrelated purchase and model dependencies. Resolution: preserve the MIT SQLite module and renderer concepts, implement a small independent local simulator with only two Python dependencies.
2. **Chinese render fonts.** Generic Latin defaults cannot reliably render Chinese. The renderer now checks Microsoft YaHei / Noto CJK / PingFang, accepts an explicit local font path, and the real Chinese portrait sample was visually inspected. Fonts are not redistributed. Emoji coverage remains platform-dependent.
3. **Replay and duplicate clicks.** A render request needs an immutable revision snapshot, not whatever the editor contains when a worker later runs. The implementation snapshots input and deduplicates exact revision fingerprints, verified by actual repeated requests.
4. **Cancellation and process interruption.** Stopping work without publishing a partial movie requires checking during frame generation and again before final rename. Temporary files are cleaned; restart marks unfinished jobs interrupted. Actual cancel and injected-render-failure/retry cases passed.
5. **Clean startup dependency gap.** The base interpreter had Pillow and system FFmpeg but not imageio-ffmpeg. A clean venv installed the exact Pillow/imageio-ffmpeg versions successfully from PyPI. A hash-locked requirements file was generated from official release metadata. The starter installs the bundled binary dependency automatically.
6. **Browser verification blocked by environment.** Starting local Chromium through Playwright failed at an OS socket permission check. An explicitly approved execution retry produced the same failure. The available separate cloud browser could not open the loopback app, and a subsequent binding was refused by the URL policy. No restriction was bypassed. Therefore no browser end-to-end success, mobile screenshot, or UI recording is claimed. Static JavaScript parsing and real HTTP/backend/render tests are separate evidence, not substitutes for browser playback.
7. **Pre-event baseline missing.** The provided public checkout was shallow at a September 23 commit. No earlier SHA was available in it. The package records this limitation and the actual supplied source SHA instead of inventing historical proof.

## Feedback on the simulation approach

The officially clarified simulation route let development focus on the actual creator workflow rather than requiring an unavailable runtime integration. A bounded rule layer made unsupported-command handling and evidence easy to test. This is feedback about building the simulator, not a claim to have used or evaluated the Alexa SDK, Agent Skill tools, MCP Toolkit, AWS credits or device runtime.
