Three steps

  1. Upload a video you own or have permission to process. Files stay in this workstation's runtime directory.
  2. Review the original and each interval. Suggestions are technical heuristics. Change the duration or sharpness preference, choose intervals and optional exposure/sharpening.
  3. Check the approval box and render. Download the MP4, JSON/CSV measurements and audit bundle. Previous outputs and failure logs stay available on disk.

What is measured

Mean grayscale luma, dark/white pixel fractions, Laplacian variance, absolute frame differences and grayscale histogram distance are measured using real OpenCV 5. Nothing is randomly scored. Four samples per second are grouped into one-second review bins.

Limits

Intentional darkness can be flagged. Smooth animation or a blank wall can be soft without being out of focus. Motion and lighting changes can look like cuts. Sharpening cannot recover lost detail. Exposure adjustments cannot reconstruct clipped highlights or shadows. No neural model, identity recognition or semantic judgment is used.

VFR inputs and uncommon audio layouts need manual synchronization review. Only the first audio track is retained. A browser may not preview every accepted source codec, even if OpenCV can analyze it; the rendered H.264/AAC MP4 is the compatible review output.

Cancellation & restart

Cancel stops pending analysis or the active FFmpeg process. Original files, failed attempts and previous successful outputs are retained. Restarting marks active jobs as interrupted; use Retry analysis to resume safely. Processing is one job at a time. Do not start multiple server workers against one runtime directory.

Privacy & storage

Default binding is 127.0.0.1. No cloud or paid API is called. Do not expose the server publicly. AWS deployment is an optional private EC2 container through SSM; it requires separate account, permissions and spending approval. It has not been deployed or validated.

Uploads are capped at 150 MB, 180 seconds, 120 FPS and 1920×1080 equivalent pixels. There is a 30-job cap and 10 renders per job. Stop the application before manually archiving runtime folders. No automatic deletion is performed.
